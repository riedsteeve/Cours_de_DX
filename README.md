# But du projet

Donjon du Marchand est une application complète.

une API Spring Boot exposant un CRUD complet sur le catalogue d’objets, et un CRUD simplifié sur les
commandes

un front séparé qui consomme cette API en session, avec CORS et CSRF correctement configurés
une validation des entrées et une gestion d’exceptions cohérentes, visibles jusque dans l’interface.
